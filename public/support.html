Help for parents and teachers using Kidsy: Learn With Fun.

Get help or report a problem

Open a request on the Kidsy help page. Please say which device you use and what happened.

Common questions

How do I change the grade? Open Me → Profile.

How do I make an exam on certain material only? Open Exams → Build my exam, tick the material, choose how many questions and press Start.

How do I start the scores again? Open Me → Rewards → Reset. Each reset asks first.

Does Kidsy work offline? Yes. Only word look-ups, translations and the optional online voices need the internet.
